# docs-qa

Ответы на вопросы по документам компании со ссылками на источники (RAG).

## Структура

- `docs_qa/index.py` — читает Markdown, TXT, PDF и DOCX, режет на фрагменты по абзацам с заголовком раздела, ищет через TF-IDF по символьным n-граммам.
- `docs_qa/answer.py` — промпт с найденными фрагментами и провайдеры модели (`gigachat`, `openai`, `none`). При слабом совпадении (ниже `MIN_SCORE`) отвечает «В документах этого нет».
- `docs_qa/cli.py` — команды `index`, `ask`, `eval`.
- `examples/docs` и `examples/questions.jsonl` — вымышленные документы и 18 вопросов для оценки поиска.
- `tests/test_docs_qa.py` — нарезка, поиск, промпт и отказ без контекста.

## Команды

```
pip install -r requirements.txt
python -m docs_qa index examples/docs
python -m docs_qa eval examples/questions.jsonl
python -m docs_qa ask "Сколько суточных за границей?"
pytest
```

## Правила

- Любое изменение поиска проверяется командой `eval`: сейчас верный документ первым в 17 вопросах из 18 и в первой тройке во всех 18. Результат не должен ухудшиться.
- Модель отвечает только по найденным фрагментам и указывает их номера.
- Чтобы попробовать эмбеддинги или переранжирование, добавлять их как отдельный режим и сравнивать на том же наборе вопросов.
