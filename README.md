# Вопросы по документам компании

Сотрудник спрашивает своими словами — «можно взять пару дней за свой счёт на свадьбу?» — и получает короткий ответ со ссылкой на документ и раздел, откуда он взят. Это схема RAG (retrieval-augmented generation): сначала находим нужные куски документов, потом нейросеть отвечает строго по ним.

## Как устроено

1. **Нарезка.** Документы (Markdown, TXT, PDF, DOCX) режутся на фрагменты по абзацам, и к каждому приклеивается заголовок раздела. Без заголовка фраза «до пяти дней без сохранения зарплаты» теряет смысл, а с ним поиск понимает, что речь об отпуске.
2. **Поиск.** TF-IDF по символьным n-граммам. Для русского языка это простой и надёжный выбор: «отпуск», «отпуска» и «отпуском» совпадают по большей части букв, и обходиться без лемматизатора можно.
3. **Ответ.** Три лучших фрагмента уходят в GigaChat или любую OpenAI-совместимую модель с жёсткой инструкцией: отвечать только по ним, а если ответа нет — так и сказать. В ответе указываются номера фрагментов-источников.

Без нейросети (`LLM_PROVIDER=none`) инструмент показывает самый подходящий фрагмент с указанием документа и раздела.

## Качество поиска

В `examples` лежат шесть вымышленных внутренних документов компании (отпуска, командировки, удалёнка, безопасность, оборудование, ДМС) и 18 вопросов к ним, сформулированных обычными словами, а не цитатами из документов.

```
python -m docs_qa index examples/docs
python -m docs_qa eval examples/questions.jsonl
```

Результат: верный документ оказывается первым в 17 вопросах из 18 (94%) и попадает в первую тройку во всех 18. Единственный промах — вопрос «Какой длины должен быть пароль?», где первым нашёлся раздел про VPN в документе об удалёнке, а правильный ответ был вторым.

## Запуск

```
pip install -r requirements.txt
cp .env.example .env
python -m docs_qa index путь/к/документам
python -m docs_qa ask "Сколько суточных платят за границей?"
```

## Ограничения и что улучшить

- Без нейросети инструмент не умеет сказать «ответа нет»: он всегда покажет ближайший фрагмент. Отказ от ответа даёт только режим с моделью.
- На больших базах документов TF-IDF стоит заменить или дополнить векторными эмбеддингами и переранжированием. Набор вопросов в `examples` позволяет сравнить подходы на одних и тех же данных.
