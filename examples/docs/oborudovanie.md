# Оборудование

## Рабочий ноутбук

Ноутбук выдаётся в первый рабочий день. Плановая замена — раз в три года. Если ноутбук не тянет рабочие задачи раньше, руководитель может согласовать досрочную замену.

## Поломки

При поломке оставьте заявку в helpdesk. На время ремонта выдаётся подменный ноутбук, обычно в тот же день.

## Дополнительная техника

Второй монитор, клавиатуру и мышь выдают по запросу через helpdesk без согласования. Наушники с микрофоном — для сотрудников, у которых больше трёх созвонов в день.

## При увольнении

Всю выданную технику нужно вернуть в последний рабочий день. Обходной лист подписывает служба поддержки.
